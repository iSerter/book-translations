# Dhammapada Pali Generation Commands

Commands to generate all 26 chapters (vaggas) of the Dhammapada in Pali.

## Chapter Commands

# Chapter 1: Yamaka Vagga (20 verses)
npm run cli -- chapter generate -b dhammapada -c 1 --template dhammapada-pali -e 20 -p ai-sdk -m gpt-4o
